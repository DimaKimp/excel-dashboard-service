# Дмитрий Кимпинский — Excel-дашборды для бизнеса

Статический адаптивный одностраничный сайт для реальной услуги. Без платных зависимостей, сборщиков и серверного кода.

## Состав
- `index.html` — структура, тексты и демонстрационный дашборд
- `styles.css` — оформление и адаптация под мобильные устройства
- `script.js` — текущий год, необязательный обработчик будущей аналитической цели

## Публикация на GitHub Pages
1. Войдите в GitHub (`DimaKimp`) и создайте **новый публичный репозиторий** `excel-dashboard-service`.
2. Загрузите в корень репозитория три файла: `index.html`, `styles.css`, `script.js` (при желании README.md).
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветка **main**, папка **/(root)** и нажмите **Save**.
5. После публикации адрес будет похож на `https://dimakimp.github.io/excel-dashboard-service/` (проверьте фактический URL в GitHub Pages). Наличие сайта не подтверждено, пока он не опубликован.
6. Откройте сайт на телефоне и компьютере; проверьте ссылку на Telegram и отсутствие ошибок.
